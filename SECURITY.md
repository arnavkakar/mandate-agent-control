# Security policy

Mandate is a simulated authorization product. It does not process real payments or store card or banking credentials.

## Reporting a vulnerability

Please use GitHub's private security-advisory form:

https://github.com/arnavkakar/mandate-agent-control/security/advisories/new

Include the affected surface, reproduction steps, expected impact, and any suggested mitigation. Do not include real credentials or personal data. Please do not open a public issue until the report has been reviewed.

The project does not currently operate a paid bug-bounty program.
