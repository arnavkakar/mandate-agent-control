# Security policy

Mandate is currently a simulated authorization-control product. It does not process payments or store card or bank credentials.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/arnavkakar/mandate-agent-control/security/advisories/new). Do not open a public issue containing exploit details, credentials, personal data, or working attack payloads.

Include the affected route or component, the impact, minimal reproduction steps, and a suggested remediation if available. Remove secrets and personal information from screenshots and logs.

## Safe testing

Testing requires explicit written authorization and a defined scope. Use a dedicated test account and staging environment whenever possible. Do not perform denial-of-service testing, automated credential attacks, destructive database actions, social engineering, data exfiltration, or tests against other users' workspaces.

Good-faith reports that respect these boundaries will be investigated promptly. This policy is not authorization to test third-party services such as Railway, Google, OpenAI, GitHub, or Namecheap.
