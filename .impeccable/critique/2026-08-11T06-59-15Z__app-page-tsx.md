# Mandate full-app critique

Initial score: 23/40 (Needs Work).

## Critical findings

- Risk Activity rendered unsupported statistics in an empty workspace.
- Decision explanations synthesized budget, rule, and engine evidence in the client.
- Create Mandate was unusable at 390px.
- Repeated violet decoration and equal card grids made the product resemble a generic AI/SaaS dashboard.
- Overview prioritized passive metrics over remaining authority and human action.
- High-stakes controls lacked robust confirmation, progress, and evidence states.

## Page findings

- Auth needed stable provider fallback and less generic presentation.
- Agents needed better empty-state guidance, validation, and confirmation flows.
- Transactions needed truthful filters and contextual empty states.
- Approvals needed failed rules inline and double-submit prevention.
- Risk needed live data, denominators, and an honest empty state.
- Audit needed human-readable evidence and timestamped verification.
- Simulator needed prerequisite recovery and no false currency affordance.
- Connections needed the real API base URL and removal of pretend connectors.
- Create Mandate needed an explicit intent-to-policy-to-review pipeline.
- Decision Drawer needed authoritative rule rows and accessible dialog behavior.
- Mobile navigation needed inert hidden content, a backdrop, Escape handling, and 44px targets.

## Design direction

Replace the purple AI-SaaS template language with an Authorization Registry: warm paper, ink typography, restrained authority teal, semantic decision colors, squared ledger surfaces, and a recurring authority-position/decision-trace object.
